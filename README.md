## 🌟 Overview

**DSA-Mastery** is a complete, industry-grade repository designed to take you from absolute beginner to competitive programmer and FAANG-ready engineer. It includes:

- ✅ **Dual-language implementations** — Python 3.12+ and C++20
- ✅ **20 Jupyter Notebooks** with theory, code, and visualizations
- ✅ **300+ Curated Problems** (Easy / Medium / Hard)
- ✅ **Blind 75 + NeetCode 150 + Top Interview 150** solutions
- ✅ **AI/ML DSA Connections** — how algorithms power machine learning
- ✅ **7 Production Projects** (LRU Cache, Autocomplete, Pathfinding, etc.)
- ✅ **Benchmarks** — C++ vs Python performance comparisons
- ✅ **Interview Prep** — HR, Behavioral, System Design, Mock Interviews
- ✅ **6-Month Structured Roadmap**

## 🗺️ Learning Path

```
Phase 1 (Weeks 1-4):   Arrays → Strings → Hashing → Recursion
Phase 2 (Weeks 5-8):   Linked Lists → Stacks → Queues → Trees
Phase 3 (Weeks 9-14):  Graphs → Heaps → Tries → Sorting/Searching
Phase 4 (Weeks 15-20): DP → Backtracking → Greedy → Segment Trees
Phase 5 (Weeks 21-24): System Design → CP → Mock Interviews
```

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/DSA-Mastery.git
cd DSA-Mastery

# Run setup script
chmod +x setup.sh && ./setup.sh

# Install Python dependencies
pip install -r requirements.txt

# Or use conda
conda env create -f environment.yml
conda activate dsa-mastery

# Launch Jupyter notebooks
jupyter lab notebooks/
```

### C++ Setup

```bash
# Compile any C++ file
g++ -std=c++20 -O2 -o solution cpp/arrays/two_sum.cpp

# Or use CMake (coming soon)
```

## 🤖 AI/ML Connection

DSA is the backbone of AI/ML engineering. This repo explains:

| DSA Topic           | AI/ML Application                             |
| ------------------- | --------------------------------------------- |
| Graphs              | Neural networks, knowledge graphs, GNNs       |
| Dynamic Programming | Reinforcement learning, sequence models       |
| Trees               | Decision trees, random forests, XGBoost       |
| Hashing             | Feature hashing, embeddings                   |
| Heaps               | Priority queues in Dijkstra/A\* for AI search |
| Arrays/Tensors      | NumPy, PyTorch, TensorFlow operations         |
| Tries               | NLP tokenization, autocomplete                |
| Segment Trees       | Range queries in time-series ML               |

See [`ai_ml_connection/`](ai_ml_connection/) for detailed explanations.
